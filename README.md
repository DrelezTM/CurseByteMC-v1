## Installation 📑
* Clone Repository
  ```sh
  git clone https://github.com/DrelezTM/CurseByteMC-v1
  ```
* Install Modules
  ```sh
  npm install
  ```
* Start
  ```sh
  npm start
  ```

## Build 📑
* Install Modules
  ```sh
  npm run build
  ```
